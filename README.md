# QRCoder

一个 Chrome 扩展：生成当前网页的二维码，或右键识别图片中的二维码。二维码的生成和解码都在本地进行。纯 Vibe Coding 产物。

## 安装

需要 Chrome 116 或更高版本。

1. 打开 Chrome 的 `chrome://extensions/`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 `dist` 文件夹。
3. 可在浏览器扩展菜单中将「QRCoder」固定到工具栏。

## 使用

- **生成**：打开一个 HTTP 或 HTTPS 网页，点击工具栏中的扩展图标。可以调整前景色、背景色、图片尺寸和周围留白，并下载 PNG。低对比度、浅色前景或留白不足可能使二维码难以识别。
- **识别**：在网页图片上点击鼠标右键，选择「识别图片中的二维码」。结果会显示在独立窗口；点击「复制内容」复制，识别到 HTTP 或 HTTPS 链接时也可以选择在新标签页打开。扩展不会自动复制或打开链接。

扩展会读取选中图片的数据；网络图片需要请求原图片地址。需要登录、已失效或受到网站限制的图片可能无法读取，浏览器内部页面和某些框架中的临时图片也可能受限。识别结果仅临时存放在浏览器会话存储中，用于传递到结果窗口。

## 从源码构建

需要 Node.js 和 npm。

```bash
npm ci
npm test
npm run build
```

构建输出位于 `dist/`。源代码修改后需要重新构建，并在 `chrome://extensions/` 中重新加载扩展。测试命令使用支持 `--test-isolation=none` 的 Node.js 版本，例如 Node.js 24。

## 权限说明

扩展使用右键菜单、离屏文档和临时存储完成识别，使用当前标签页和脚本权限读取部分临时图片，使用剪贴板权限执行用户请求的复制操作。HTTP(S) 网站访问权限用于读取右键选择的跨域图片；扩展不会向服务端上传二维码内容。
